# Tornado ChatBot

A desktop AI chatbot built with PyTorch and a Tkinter GUI. Trained on an intents dataset, it answers general small-talk questions (greetings, thanks, jokes) as well as tornado-specific questions covering how tornadoes form, tornado-prone regions, and tornado safety.

## Features
- Tkinter desktop chat window ("TORNADO CHATBOT") with a message history pane and a send box
- Bag-of-words + feedforward neural network intent classifier (PyTorch)
- Confidence-thresholded responses - replies "I do not understand..." when the model isn't confident enough
- Intents covering: greetings, goodbye, thanks, general AI questions (what is AI, what language is it written in, what can AI do), jokes, and tornado topics - formation, tornado regions/Tornado Alley, and tornado safety

## Tech stack
- Python
- PyTorch (neural network training and inference)
- NLTK (tokenization, stemming, bag-of-words)
- Tkinter (desktop GUI)

## Project structure
- `app.py` - Tkinter GUI application (entry point for the chat window)
- `chat.py` - loads the trained model and generates responses (`get_response`)
- `model.py` - `NeuralNet` PyTorch model definition
- `nltk_utils.py` - tokenization, stemming, and bag-of-words helper functions
- `train.py` - trains the neural network on `intents.json` and saves `data.pth`
- `main.py` - command-line chat loop (alternative to the GUI)
- `intents.json` - training data: intent tags, example patterns, and responses
- `data.pth` - trained model weights and vocabulary (generated by `train.py`)

## Getting started
```bash
git clone https://github.com/Anandhu336/Tornado_chat_Bot.git
cd Tornado_chat_Bot
pip install torch nltk
python -c "import nltk; nltk.download('punkt')"
```
A trained `data.pth` is already included, so you can run the chatbot directly. To retrain on an updated `intents.json`, run `python train.py` first to regenerate `data.pth`.

## Usage
- Run `python app.py` to open the Tkinter chat window, type a message, and press Enter or click Send.
- Or run `python main.py` for a simple command-line chat loop.
